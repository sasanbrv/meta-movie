# 🎬 Meta Movie

**Meta Movie** is a modern movie discovery web application that helps you find movies, explore their information, and watch their trailers in one place.

Built with **React** and **Vite**, the project provides a simple and responsive interface for discovering movies through a REST API.

## ✨ Features

* 🔎 Search and discover movies
* 🎞️ Explore movie information
* ▶️ Watch movie trailers
* 📱 Responsive and modern UI
* ⚡ Fast development with Vite
* 🔗 REST API integration
* 🧩 React Hooks for managing application logic
* 🎨 Tailwind CSS for styling
* 🛡️ Zod for data validation

## 🛠️ Tech Stack

* **React**
* **Vite**
* **JavaScript**
* **Tailwind CSS**
* **Axios**
* **REST API**
* **Zod**
* **React Hooks**

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/sasanbrv/meta-movie.git
```

Navigate to the project directory:

```bash
cd meta-movie
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local address shown by Vite in your terminal.

## 🌐 API

Meta Movie uses a REST API to retrieve movie-related data.

Axios is used for making API requests, while Zod can be used to validate API responses and keep the application's data layer safer and more predictable.

## 🎯 Purpose

The goal of Meta Movie is to provide a simple and enjoyable way to discover movies without having to visit multiple websites to find basic movie information and trailers.
